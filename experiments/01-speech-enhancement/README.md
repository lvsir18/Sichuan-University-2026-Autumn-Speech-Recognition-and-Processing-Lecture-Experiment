# 实验一：语音增强

负责人在 `feat/exp01-speech-enhancement` 分支完成本目录。

## 建议教学主线

1. 构造或选择干净语音与噪声，按固定 SNR 混合。
2. 展示时域波形、频谱/语谱图和增强前后音频。
3. 比较传统谱减法与一个轻量神经网络增强模型。
4. 计算 SNR、SI-SDR、STOI；PESQ 仅在许可证和环境允许时启用。

## 提交前必须补齐

- 数据与噪声来源、许可证、固定样本清单。
- 独立 Dockerfile、Compose 和依赖文件。
- 中文实验界面或可操作 Notebook。
- 学生实验指导书、结果导出和基础测试。
