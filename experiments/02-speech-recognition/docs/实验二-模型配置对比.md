# 实验二：模型与配置对比

## 实验目标

在控制变量条件下比较不同模型，理解参数规模、准确率和推理速度之间的关系。

## 操作步骤

1. 确认页面顶部的 FLEURS 中文迷你测试集已经准备完成。
2. 进入“02 模型配置对比”，选择“固定数据集 12 条”，同时勾选 tiny、base、small。
3. 固定 beam size 为 1，运行并下载完整结果。平台以全部字符错误数除以全部参考字符数计算微平均 CER。
4. 将 beam size 改为 5，再运行一次。
5. 将两次结果整理为表格，至少比较微平均 CER、SER、整体 RTF 和总耗时。

## 变量设计

- 自变量：模型名称；第二轮可将 beam size 作为另一自变量。
- 因变量：CER、WER、RTF、耗时。
- 控制变量：音频、参考文本、语言、硬件、容器资源、预处理方式。

## 讨论边界

单条音频只能说明案例差异，不能代表模型总体能力。正式结论至少应使用同一测试集上的宏观统计，并报告样本数、总时长和领域。
