# 实验一：语音识别基础与评价

## 实验目标

1. 理解“音频输入—声学/端到端模型—解码—文本输出”的基本链路。
2. 会计算并解释 CER、WER、SER 和 RTF。
3. 能根据替换、删除、插入三类错误分析识别结果。

## 建议学时

2 学时。前 20 分钟由教师说明指标，50 分钟完成操作，20 分钟讨论误差。

## 操作步骤

1. 打开实验台，进入“01 识别与评测”。
2. 在页面顶部点击“下载并校验数据集”，确认显示 12 条且 SHA-256 已校验。
3. 先选择“内置演示”，理解操作和指标；再切换“固定数据集（真实识别）”。
4. 从 FLEURS 固定子集中选择第 1 条，播放并核对参考文本，运行 tiny 模型。
5. 观察 CER、WER、SER、RTF 和字符编辑明细。注意：中文句子没有空格时，WER 的教学意义有限，应优先采用 CER。
6. 固定该语音，分别设置 beam size 为 1 和 5，下载两份 JSON。
7. 选择另外两条固定语音重复实验。自行上传只作为课后扩展，不进入班级统一统计。

## 思考题

1. CER 为 0 时，SER 为什么一定为 0？反过来是否成立？
2. RTF 小于 1 表示什么？它是否等同于低延迟流式识别？
3. 标点和大小写是否应该计入错误？评价前的文本规范化会如何影响结论？

## 报告要求

写明设备、模型、参数、音频来源与参考文本；粘贴两组结果；解释至少一种编辑错误。不得把 `simulated` 结果写成真实模型性能。
