# 实验三：CTC 解码与语言模型

## 实验目标

1. 理解 CTC 中空白符和重复标签的折叠。
2. 理解贪心解码只保留局部最优路径，而束搜索保留多个前缀。
3. 理解语言模型分数如何与声学分数加权。

## 操作步骤

1. 进入“03 解码与语言模型”，将 beam width 设为 1、语言模型权重设为 0。
2. 记录输出和候选分数。
3. 依次将 beam width 改为 3、5、10，观察候选数量和最优结果。
4. 固定 beam width 为 10，从 0 开始以 0.1 为步长增大语言模型权重，找到输出发生变化的临界区间。
5. 解释“声学模型稍偏向同音字，但语言模型更偏好常见搭配”这一现象。

## 核心公式

`总分 = 声学对数概率 + α × 语言模型对数概率`

α 过小可能无法利用语言约束；α 过大则可能让语言模型压过真实声学证据，产生“听起来没说但句子很通顺”的错误。
